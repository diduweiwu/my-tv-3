# 我的电视·〇 项目分析文档

## 项目概述

**项目名称**: 我的电视·〇 (My TV 0)  
**项目类型**: Android电视视频播放应用  
**开发语言**: Kotlin  
**最低SDK版本**: 21 (Android 5.0)  
**目标SDK版本**: 35 (Android 15)  
**包名**: com.lizongying.mytv0  
**项目地址**: https://github.com/lizongying/my-tv-0

## 项目简介

这是一个专为Android电视设备设计的视频播放软件，主要功能是播放自定义视频源。用户可以通过配置不同的视频源文件（支持txt/m3u/json格式）来观看各种电视频道。应用支持遥控器和触屏操作，具有频道收藏、节目单查看、远程配置等功能。

## 核心功能

### 1. 视频源管理
- **支持多种格式**: txt、m3u、json格式的视频源文件
- **多源选择**: 支持配置多个视频源并切换
- **本地文件支持**: 可设置本地文件作为视频源
- **自动更新**: 应用启动后可自动更新视频源
- **缓存机制**: 缓存视频源到本地文件

### 2. 播放功能
- **多格式支持**: HLS、DASH、RTSP、RTMP等流媒体协议
- **软硬解切换**: 支持软件解码和硬件解码切换
- **循环播放**: 支持视频循环播放
- **错误重试**: 播放失败时自动重试
- **频道记忆**: 记住上次播放的频道

### 3. 频道管理
- **频道分组**: 按组分类显示频道
- **频道收藏**: 支持收藏常用频道
- **频道号**: 支持3位频道号快速切换
- **换台反转**: 可反转上下键换台逻辑
- **默认频道**: 可设置启动时播放的默认频道

### 4. EPG节目单
- **EPG支持**: 支持XMLTV格式的EPG数据
- **多EPG地址**: 支持配置多个EPG地址
- **EPG缓存**: 缓存EPG数据到本地
- **节目单显示**: 长按左键显示节目单

### 5. 远程配置
- **内置服务器**: 内置HTTP服务器（端口34567）
- **局域网配置**: 局域网内可通过浏览器配置
- **二维码配置**: 扫描二维码快速配置
- **配置同步**: 通过网络配置视频源和设置

### 6. 代理设置
- **HTTP代理**: 支持HTTP代理
- **SOCKS代理**: 支持SOCKS代理
- **全局代理**: 代理设置影响所有网络请求

### 7. 用户界面
- **电视适配**: 专为电视设备设计，支持Leanback
- **触屏支持**: 同时支持触屏设备操作
- **手势控制**: 支持音量、亮度调节手势
- **时间显示**: 可显示当前时间
- **紧凑菜单**: 可配置紧凑的菜单样式

## 技术架构

### 技术栈

#### 核心框架
- **Kotlin**: 主要开发语言
- **Android SDK**: Android原生开发
- **Leanback**: Android TV UI框架

#### 媒体播放
- **ExoPlayer (Media3)**: Google官方媒体播放器
  - media3.exoplayer: 核心播放器
  - media3.exoplayer.hls: HLS支持
  - media3.exoplayer.dash: DASH支持
  - media3.exoplayer.rtsp: RTSP支持
  - media3.datasource.okhttp: OkHttp数据源
  - media3.datasource.rtmp: RTMP支持
- **FFmpeg**: 硬件解码支持（lib-decoder-ffmpeg-release.aar）

#### 网络通信
- **OkHttp**: HTTP客户端
- **NanoHTTPD**: 轻量级HTTP服务器

#### 数据处理
- **Gson**: JSON解析
- **Gua**: 自定义加密/解密库

#### 图像处理
- **Glide**: 图片加载和缓存

#### 其他
- **ZXing**: 二维码生成和扫描
- **Coroutines**: Kotlin协程处理异步任务

### 核心类说明

#### MainActivity
主Activity，负责：
- 管理所有Fragment的生命周期
- 处理遥控器和触屏事件
- 处理手势操作（音量、亮度调节）
- 管理播放器状态
- 处理返回键和其他按键事件

#### MainViewModel
主ViewModel，负责：
- 频道数据的加载和解析
- EPG数据的获取和解析
- 视频源的导入和管理
- Logo图片的预加载
- 配置的更新和同步

#### SimpleServer
内置HTTP服务器，负责：
- 提供局域网配置接口
- 处理远程配置请求
- 生成配置二维码

#### TVModel
频道业务模型，封装：
- 频道基本信息
- 播放状态
- 收藏状态
- EPG数据
- 错误信息

## 配置格式

### TXT格式
```
组名,#genre#
标题,视频地址
```

### M3U格式
```
#EXTM3U x-tvg-url=""
#EXTINF:-1 tvg-id="" tvg-chno="" tvg-name="标准标题" tvg-logo="图标" group-title="组名",标题
#EXTVLCOPT:http-user-agent=
#EXTVLCOPT:http-referrer=
视频地址
```

### JSON格式
```json
[
  {
    "group": "组名",
    "name": "标准标题",
    "title": "标题",
    "logo": "图标",
    "number": "频道号",
    "uris": [
      "视频地址"
    ],
    "headers": {
      "user-agent": ""
    }
  }
]
```

## 操作说明

### 遥控器操作
- **中键**: 打开视频列表
- **右键**: 打开配置
- **左键**: 打开节目单
- **返回键**: 关闭视频列表/配置
- **上下键**: 切换频道
- **数字键**: 输入频道号

### 触屏操作
- **单击**: 打开视频列表
- **双击**: 打开配置
- **长按**: 打开节目单
- **下滑**: 切换到下一个频道
- **左滑**: 调节亮度
- **右滑**: 调节音量
